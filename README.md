# Kushagra Prajapati — Portfolio

Personal portfolio of **Kushagra Prajapati**: AI & web developer and UI/UX designer, B.Tech CSE (AI) at the University of Lucknow.

A single, dependency-free `index.html`: hand-written HTML, CSS and JavaScript, no build step.

## Featured projects
- **Backbench** — student platform for FoET, University of Lucknow · [backbeench.in](https://www.backbeench.in)
- **INDRA-X** — air-gapped multi-agent AI workbench with a UE5 + ROS 2 digital twin
- **RASAD** — route-aware supply dispatch for forward posts · [live](https://rasad-prototype.vercel.app) · [code](https://github.com/kushagracode18/rasad-prototype)
- **Nivaran** — AI grievance triage and routing

## Run locally
Open `index.html` in a browser. No install needed.

## Edit content
All content lives in the objects at the top of the `<script>` block: `CONFIG` (links), `PROJECTS`, `SERVICES`, `LOG` (hackathons) and `FAQ`. Add a project by adding one object to `PROJECTS`.

## Deploy
- **Vercel:** import this repo; framework preset "Other", no build command.
- **GitHub Pages:** Settings → Pages → deploy from branch `main`, folder `/ (root)`.
